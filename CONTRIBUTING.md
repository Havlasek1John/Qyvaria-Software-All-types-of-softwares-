# Contributing to Qyvaria Softwares

Thank you for helping improve Qyvaria Softwares.

This repository is planned to be updated daily with new software, bug fixes, UI improvements, installers, and tests.

## Ways to Contribute

- Report bugs
- Suggest new Qyvaria apps
- Improve UI design
- Improve installers
- Improve Linux desktop integration
- Improve Windows setup scripts
- Add tests
- Add documentation
- Add screenshots
- Add translations

## Development Rules

1. Keep apps safe by default.
2. Do not make fake performance or compression claims.
3. Add warnings before destructive actions.
4. Keep the UI clean and readable.
5. Support Windows and Linux when possible.
6. Add tests for important features.
7. Update the README when adding a new app.

## Pull Request Checklist

Before opening a pull request:

- [ ] The app still starts
- [ ] Existing tests pass
- [ ] New features have documentation
- [ ] Install scripts still work
- [ ] No private data is included
- [ ] No passwords, tokens, or keys are committed
- [ ] License headers are respected
