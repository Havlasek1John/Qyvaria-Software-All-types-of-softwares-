# Code of Conduct

## Our Standard

This project welcomes respectful collaboration.

Examples of good behavior:

- Helpful bug reports
- Clear feature suggestions
- Respectful technical disagreement
- Constructive pull request reviews

Examples of unacceptable behavior:

- Harassment
- Hate speech
- Personal attacks
- Sharing private data without permission
- Spam

## Enforcement

Maintainers may remove comments, close issues, or block users who harm the project community.
