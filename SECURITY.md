# Security Policy

## Supported Versions

This repository is updated frequently. Security fixes should target the latest version unless a specific app release is still being maintained.

## Reporting a Vulnerability

Please do not post private security issues publicly if they involve:

- File deletion risk
- Unsafe system optimization
- Data leaks
- Password/token exposure
- Installer abuse
- Privilege escalation
- Archive extraction path traversal

Open a private security advisory on GitHub if available, or contact the maintainer privately.

## Safety Principles

Qyvaria Softwares should:

- Avoid destructive actions by default
- Warn before risky operations
- Keep backups where possible
- Avoid collecting private information
- Mask sensitive values in reports
- Never include real private user data in demo files
