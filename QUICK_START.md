# Quick Start

## Clone

```bash
git clone https://github.com/YOUR_USERNAME/qyvaria-softwares.git
cd qyvaria-softwares
```

## Linux Install

```bash
chmod +x install_all_linux.sh
./install_all_linux.sh
```

## Windows Install

Double-click:

```text
install_all_windows.bat
```

## Build / Test

```bash
python -m compileall .
```

## Daily Update

Update:

```text
CHANGELOG.md
```

Then commit:

```bash
git add .
git commit -m "Daily Qyvaria software update"
git push
```
